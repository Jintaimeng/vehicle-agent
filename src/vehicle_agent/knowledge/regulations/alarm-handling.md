# 疲劳驾驶学习档案

- document_id: fatigue-training
- title: 疲劳驾驶学习档案
- section: 第1节 签到记录
- alarm_types: driver_fatigue

企业保存疲劳驾驶学习签到，用于内部档案，不作为行驶报警的处置依据。

# 手机使用

- document_id: phone-rules
- title: 手机使用处置要点
- section: 第1节 行驶中通话
- alarm_types: phone_use

车辆行驶中驾驶员手持电话或查看屏幕时，应语音警告并记录报警，不要把它当成疲劳驾驶停车事件。

# 超速

- document_id: speeding-rules
- title: 超速处置要点
- section: 第1节 速度提示
- alarm_types: speeding

车辆速度超过路段限速时，应提示驾驶员减速并通知企业安全管理员，不要按设备离线处理。

# 摄像头遮挡

- document_id: camera-rules
- title: 摄像头遮挡排查要点
- section: 第1节 画面缺失
- alarm_types: camera_occlusion

摄像头画面被遮挡时，先核对镜头和供电，再决定是否按驾驶行为报警处置。
