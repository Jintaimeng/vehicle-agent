# 疲劳驾驶处置

- document_id: fatigue-rules
- title: 疲劳驾驶处置要点
- section: 第2节 行驶中的报警
- alarm_types: driver_fatigue

车辆行驶中出现疲劳驾驶报警时，应联系驾驶员并要求就近停车休息，同时通知企业安全管理员复核。单次报警本身不能单独证明连续驾驶时长。

# 设备离线排查

- document_id: device-offline-rules
- title: 设备离线排查要点
- section: 第1节 视频缺失
- alarm_types: device_offline

设备短时间离线或视频缺失时，先核对设备在线状态和供电，不要直接认定驾驶员存在危险驾驶行为。
